## template-studio: テンプレート選択時に TypeError が出る不具合を修正

- 症状: テンプレート生成タブでテンプレートを選択すると `Uncaught TypeError: Cannot read properties of undefined (reading 'length')`（`index-BR0tpSsj.js:68:11339`）。
- 原因: 旧バンドルの `c.rows.length` (= `TableInput` の `table.rows.length`) がクラッシュ箇所。`loadTemplate()` が `setTable(null)` で行シード待ち状態にした直後、300ms の抽出 debounce の間は旧テンプレートの変数が描画され続け、`VariableForm` が `tableState` に `rows` を持たせず `TableInput` へ渡していた。
- 修正 (`src/components/VariableForm.jsx`):
  - `TableInput`: `table.rows?.length ? table.rows : [blankTableRow(columns)]` に変更。
  - `VariableForm` の `tableState` に `rows: []` 既定値を追加（`table` が null でも rows が存在するように）。
- `npm run build` 成功。新バンドル `index-CLpVqX7U.js` に null ガードが入っていることを確認。稼働中のサーバー (localhost:3001) が新バンドルを配信していることを確認。
- 教訓: `App.jsx` が `setTable(null)` を「テンプレートから行を読み込む合図」として使っているため、null から組み立てる props は下流で Must フィールドをデフォルト埋めする必要がある。
