- **要求**：①テーブル多すぎ対策のフィルタ（既存維持）②1 つの Excel 列を複数 DB 列へ ③Excel に無い DB 列の既定値 ④1 つの Excel を複数テーブルへ ⑤INSERT の出力開始行指定。
- **モデル変更 `shared/mapping.js`**：マッピング正規形を `tables: [{ tableId, pairs, defaults }]` に拡張（旧単一テーブル形式 tableId+pairs は自動変換、互換用に tableId/pairs も出力）。`buildInsertSql` は `tables` 配列を受け表ごとに INSERT を生成（存在しない表・0 件の表は警告してスキップ、他表は継続）。`defaults` は「pairs 未割当の DB 列」に適用：空欄は使わず、`CURRENT_TIMESTAMP / NOW() / DEFAULT` と `'...'` 引用済みリテラルは生値、それ以外は列型判定（数値無引用 / クォート / 日付 ISO 変換、不正値は警告付き NULL）。options に `startRow: 1`（1 起点のデータ行）追加。同一 Excel 列の複数 DB 列割当は同一テーブル内も可（DB 列の重複のみ先頭 1 件）。
- **UI `src/excel/`**：`MappingPanel.jsx` を全面改修——テーブル一覧をチェックボックス化（フィルタ + 50 件ずつ段階描画、チェック順に INSERT 生成）、表ごとに `TableMappingEditor`（マッピング行 = Excel 列 select × DB 列 select × 削除、行追加ボタン、検索 / 100 行ずつ段階描画、折りたたみ式の既定値エディタ = 未割当列の検索 + 50 件ずつ入力欄）。`ExcelStudio.jsx` は状態を `tableMappings` 配列に変更（ファイル/表切替時は全表を自動マッピング、保存済み読込後は pinned）。`InsertOutput.jsx` に「開始行（データ行）」数値入力と表別統計タグ（n 文 · n 列 · 既定値 n）追加。`styles.css` に `.map-table-* / .tm-*` 追加。
- **サーバー**：`server/mapping.js` info に `tableCount / defaultCount` 追加、保存時は tables 合計でペア有無判定。`/api/mapping/insert` は `tables` 配列を透過（旧 table/pairs も互換）。

## Excel→INSERT 第 4 弾：1 テーブル = 1 JSON（ファイル名を保存名に紐づけ）
- **要求**：マッピング JSON を「1 テーブルにつき 1 ファイル」に分割し、JSON ファイル名を保存時の名前に紐づける。その他（表→Excel 方向・表フィルタ・既定値・複数表・開始行・Windows 実行ファイル）は維持。
- **共通関数 `shared/mapping.js`**：`safeFileStem`（Unicode 文字は保持、Windows 禁則文字・制御文字・cmd 特殊記号を `_` 置換、予約名・パス遷移を回避）、`mappingFileId(name, tableId)` = `<保存名>__<schema.table>` を追加。`normalizeMapping` が `groupName / groupFileCount / tableIndex` を透過（旧 JSON は groupName = name とみなす）。
- **保存形式 `server/mapping.js` を全面改修**：1 回の保存で tables[] を分解し `data/mappings/<保存名>__<表名>.json` を N 個書き出す（各ファイル `tables` は 1 要素、互換用 `tableId/pairs/defaults` も保持）。`groupName`（= 保存名）でグループ化し `listMappingGroups / getGroupMapping / deleteMappingGroup` を提供。同名再保存で表を減らした／名前を変えた場合の古いファイルは自動削除（`replaceGroup`）。`safeId` は Unicode を許可しつつパス遷移を拒否。旧「1 ファイルに複数表」JSON も読込・一覧・削除可能。
- **API `server/index.js`**：`GET /api/mappings` が `{ items, groups }` を返却、`GET|DELETE /api/mappings/group/:name` を追加、`POST /api/mappings` は `{ id, ids, groupName, files, items, deleted, mapping(統合), info }` を返す（旧 `id / mapping / info` キーは維持）。`src/api.js` に `getMappingGroup / deleteMappingGroup` と `saveMapping(mapping,id,replaceGroup)`。
- **UI `src/excel/`**：`ExcelStudio` は `currentMappingRef`（`group:<保存名>` / `file:<ID>`）と `currentGroupName` で保存・読込・削除を管理。保存時 `replaceGroup` を送る。`MappingPanel` の保存欄に「生成されるファイル名プレビュー」、選択肢を「保存名ごと（全表まとめて読込）」/「個別テーブル JSON（CLI 用 ID）」の 2 つの optgroup に分割。`styles.css` に `.map-file-preview`、App の nav-context に「1 テーブル = 1 JSON」を追記。
- **CLI `cli/generate-insert.mjs`**：`--mapping` に「保存名（全表）/ ファイル ID（1 表）/ JSON パス」を許容、保存名は同名グループの全 JSON を `tableIndex` 順に統合。`--group <name>` を追加、`--list` は保存名→ファイル ID の階層表示。旧形式 JSON パスも従来どおり可。`generate-insert.bat` は変更不要（引数透過）。
- **検証**：新規純関数 11 項目（ファイル名・禁則文字・グループ情報・2 表 2 ファイル・各 1 表・一覧/復元・表削減/改名時の掃除・旧形式互換・グループ削除）、HTTP 23 項目、CLI 19 項目（保存名指定 / 個別 ID / --group / bat 実実行 / Web API と SQL 完全一致）、SSR Excel 6 + DB 6、既存純関数 12 + 14 + 16 + 10、DB HTTP 11、すべて合格。`npm run build`（295.38 KB JS / 31.14 KB CSS、index-ZC3HjCd1.js）。3001 再起動済み。
- 注意：保存名に日本語を使うと JSON ファイル名も日本語になる（Windows / Node は動作可）。Windows cmd で扱う場合は `generate-insert.bat --list` の ID をコピーするか ASCII の保存名を使うと安全。1 ファイル = 1 表だが内部表現は `tables: [1件]` + 互換フィールド。
