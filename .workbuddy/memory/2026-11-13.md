# 2026-11-13

- 新增可运行项目 `template-studio/`（React + Vite + Node/Express，无数据库）：实现「Web 页面输入模板 → 自动提取变量 → 动态生成变量输入框 → 填写并实时生成代码」。
- 关键设计：变量语法 `{{name}}` / `{{name:type}}`，可选 YAML front-matter 声明 `title / outputExt / vars{label,type,default,required,options,placeholder,description,joiner}`；类型 text/textarea/code/number/boolean/select/date/list。
- 后端 `server/engine.js` 为纯函数：splitTemplate（前端 YAML 解析）→ extract（扫描去重、合并元数据、记录出现次数与行号、告警）→ render（按类型格式化，用 replace 回调避免 `$&` 误展开，返回 missing/unused/replaced/stats）。`server/store.js` 用 `data/templates.json` 做轻量持久化并内置 3 个示例模板（Spring Boot Service / React 组件 / AI向け `<spec>` タスク票）。`server/index.js` 提供 /api/extract、/api/render、/api/templates CRUD、/api/health，并在 dist 存在时托管 SPA。
- 前端 `src/App.jsx` 三栏：模板编辑器 / 动态变量表单 / 实时代码预览（复制・下载・缺失变量提示），模板变更与值变更分别做 300ms / 180ms debounce；切换模板保留同名已填值。示例模板刻意向日系 FC / `<spec>` 场景靠拢。
- 验证结果：npm install 167 包 0 漏洞；vite build 成功（155KB JS / 7.4KB CSS）；health、模板列表、extract（9 变量 / 11 处 / required 生效）、render（11 处替换）、SPA root HTTP 200、模板保存→删除 roundtrip 全部通过。服务以 `node server/index.js` 跑在 3001，`npm run dev` 为 5173(Vite)+3001(API) 并行开发模式。

- 追加「变量变换」能力：新增 `shared/transforms.js`（前后端共用纯 ESM，单一真实源），含表达式解析、13 个 filter 目录、sequence 连番、toBaseValue/applyFilters。语法 `{{name | upperFirst | snake}}`、`{{name | seq(start=1, pad=2, format='...{n}. {v}...')}}`、`{{no | counter(pad=3)}}`；VAR_RE 改惰性匹配以支持 format 中的 `{n}`。

- 新增 `sequence` 变量类型（開始/終了/増分/桁数/区切り 四个输入 + 预览），`counter` 专用变量自动识别为只读 autoCounter。`server/store.js` 的 ensure() 改为增量补齐内置 seed，不覆盖用户已保存模板；新增「変数変換デモ（命名規則・連番）」模板。App 支持 `?tpl=<id>` 直接打开指定模板；新增 `start.bat` 双击启动（自动装依赖/构建/检测端口）。
