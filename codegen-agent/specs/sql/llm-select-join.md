# 入金明細と入金ヘッダの結合照会

## 対象
- 種別: SELECT
- テーブル: 入金明細

## 概要
入金明細と入金ヘッダをアプリケーションIDで結合し、
明細ID・入金額・ステータス・入金日を取得する。
抽出条件はアプリケーションID、入金日、入金額の下限とする。
結果は明細IDの降順で並べる。

## 変数
- アプリケーションIDは {{applicationId}} を使う。
- 入金日は {{receiptDate}}、入金額の下限は {{minAmount}} を使う。
