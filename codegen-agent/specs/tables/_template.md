# 表構造テンプレート

このファイルは雛形です（`_` 始まりなのでローダは読みません）。
使い方：コピーして **`<テーブル名>.md`** にリネームし、テーブル名・日本語名・カラムを書き換えてください。
**1 ファイル 1 テーブル**。ファイル名と `## テーブル` のテーブル名（英語物理名）を一致させてください。

## テーブル
- テーブル名: <table_name>
- テーブル日本語名: <日本語の表名>

## カラム
| カラム名 | 日本語名 | 型 | NOT NULL | PK |
| --- | --- | --- | --- | --- |
| id | 識別子 | bigint | YES | YES |
| application_id | アプリケーションID | varchar(32) | YES | NO |
| status | ステータス | varchar(16) | NO | NO |
| created_at | 作成日時 | timestamp | NO | NO |
| updated_at | 更新日時 | timestamp | NO | NO |

## 備考（任意）
- このテーブルが何を表すか、どの機能から使われるかを日本語で書く。
- 変数は共通 md で `{{key=value}}` のように定義し、ここでは参照のみ行う。
- 最終 SQL は sqlgen が決める。ここには構造だけを書く（SQL 文は書かない）。

## 書き方の約束
- **`カラム名` は英語の物理名**（SQL に書く名前）。**`日本語名` は仕様書側の論理名**。
  仕様書・prompt では日本語名を使ってよいが、大模型へ渡す前に Java が英語物理名へ変換する。
- `テーブル日本語名` も同じく変換表に登録される（日本語表名 → 英語表名）。
- 型の例：`bigint` / `varchar(n)` / `date` / `timestamp` / `decimal(p,s)`。
  型はバインド変数の形式判定にも使う（文字型／日付型／数値型）。
- NOT NULL / PK は `YES` または `NO` で書く（`Y` `○` `TRUE` `1` も可）。
- カラム名は半角英数字と `_` のみ（識別子）。先頭は英字か `_`。日本語名は任意の日本語文字列。
- 旧 4 列形式（`| カラム名 | 型 | NOT NULL | PK |`）もそのまま読める（日本語名は空扱い）。
- テンプレートの `<table_name>` を書き換え忘れるとローダが拒否する。
- 同じテーブル名のファイルを 2 つ作ると重複拒否になる（1 表 1 ファイルを守ること）。
- 同じ日本語名が別の英語名へ対応すると名称対応が曖昧として拒否される。
