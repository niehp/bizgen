## Agent 状態管理・多輪 function tool と usecase 分级（同日午後）
- 追加要件: 「生成過程に状態管理を導入し、LLM を多輪呼び出し、function tool を実現」「設計md の第3レベルを 機能 → usecase に変更」。
- 新パッケージ `agent/`: `ToolDefinition/ToolCall/ToolResult/ToolHandler/ToolRegistry` + `AgentState/AgentTrace/AgentResult/AgentLoop/AgentRunner/AgentContext`。LLM はツール選択のみ、引数検証・実行・状態遷移・反復抑制は 100% コード。`maxRounds/maxToolCalls/maxSameCall` の三重制限。
- LLM 層を OpenAI 互換 tools/tool_calls に対応拡張（`LlmMessage` に role=tool/toolCallId/toolCalls、`LlmRequest.toJson` に tools、`LlmResponse.parse` に tool_calls 解析）。

- CLI 追加: `tools`, `agent-gen`, `agent-sql`, `agent-trace`, `preview agent`。prompt 新增 `md/prompt/agent-java.md`, `agent-sql.md`。設定新增 `agent.maxRounds=8/maxToolCalls=30/maxSameCall=3`。
- DesignLevel.FEATURE → USECASE（`03-usecase`）。旧 feature/機能 トークンは後方互換で USECASE に変換。README/CLI/示例同步更新。
- バグ修正: `ToolResult.ok(null, ...)` が NPE を起こしていた。ツール実装は ToolCall を持たないため、ok/fail が null を安全に扱うよう修正（ToolRegistry が呼び出し ID を後で埋める）。
- 検証: javac 增量コンパイル成功、jar 再打包成功。CLI help/config/list/tools/pipeline/search/preview sql/preview agent/agent-trace 通过。自作 FakeLlm での自測: tool_calls 解析、2 ターン循環 (roles=system,user,assistant,tool,assistant)、引数不正/未登録ツール拒否、同一呼び出し 3 回での停止、usecase 変換、いずれも期待通り。
