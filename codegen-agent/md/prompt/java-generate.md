## 生成ルール

1. Java 8 構文のみを使用する（var・records・switch 式・テキストブロックは禁止）。
2. パッケージコメントは `package-info.java` 用の Javadoc ブロックとして、クラス本体とは別に `===== PACKAGE_INFO =====` セクションに出力する。
3. クラス Javadoc・フィールド Javadoc・メソッド Javadoc を必ず付ける。
4. Javadoc は日本語で「何をするか」と「なぜそうするか」を簡潔に書く。タグは @param / @return / @throws を使用する。
5. 命名規約・レイヤ規約は設計資料に従う。設計資料に無い規約は追加しない。
6. 類似コードは既存プロジェクトの書き方（命名・レイヤ・Javadoc の粒度）を合わせるための参考にのみ使う。類似コードにある機能を仕様外で持ち込まない。
7. 識別子には【用語】の英語表記を使う。日本語の識別子を作らない（日本語は Javadoc のみに使う）。
8. 【利用可能な既存 API】に記載されたメソッドだけを呼ぶ。存在しない API を推測して生成しない。
9. 生成されたコードは必ず人間がレビューする前提で、読みやすさを優先する。
10. 説明文は出力せず、以下の区切り形式のみで出力する。

## 出力形式

===== PACKAGE_INFO =====
（package-info.java の中身。Javadoc と package 宣言のみ）

===== CLASS =====
（クラスの Java ソース。package 宣言は書かない）
