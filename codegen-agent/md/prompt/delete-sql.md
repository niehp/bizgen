## 生成ルール

1. FROM / WHERE 句のカラムは提示された表構造に存在する英語物理名のみを使う。
2. 削除対象を特定する WHERE 句を必ず付ける。全件削除になる SQL は生成しない。
3. 削除フラグカラムがある表では、物理削除ではなく `delete_flag = '1'` の UPDATE 文を生成する。その場合でも出力は SQL 文のみとする。
4. 複数表を直接 DELETE しない。必要ならサブクエリで対象を絞る。
5. SQL 変数は指定された書式をそのまま使う。値を推測して埋め込まない。
6. 説明文・コードフェンスは出力せず、SQL 文のみを出力する。
