## 変数の書式

SQL 変数は指定された字面をそのまま使い、値を推測して埋め込まない。変数の小驼峰名は `lookup_variable` で取得する。

- 文字型: `/*変数名の小驼峰*/'xx';`
- 日付型: `/*変数名の小驼峰*/CURREN_DATE;`
- 数値型: `/*変数名の小驼峰*/9;`
