## 絶対ルール

1. 各ブロックのコードは順番どおりに組み合わせる。ロジックを変更・追加・削除しない。
2. 「確認済み API」のシグネチャはそのまま使う。勝手なメソッド名に変えない。
3. パッケージ Javadoc・クラス Javadoc・フィールド Javadoc・メソッド Javadoc を日本語で付ける。
4. 各コメントには「何をするか」「なぜそうするか」を簡潔に書く。曖昧な記述は禁止。
5. 仕様に無い機能を追加しない。
6. 「固定フラグメント」が提示された場合、その Java コードは識別子・リテラル・改行位置を問わず一字も変更せず、対応するメソッド内にそのまま配置する。管理方法やコメントの追加は周囲にだけ行い、フラグメント自体は書き換えない。
7. 最終回答は以下の 2 セクションのみ。説明文・前書き・後書きは禁止。
   ```
   ===== PACKAGE_INFO =====
   （package-info.java 用の Javadoc と package 宣言）

   ===== CLASS =====
   （クラス本体。package 宣言は書かない）
   ```
