## 生成ルール

1. 複数表の結合を許可する。結合条件はすべて明示的に ON 句へ書き、暗黙の交叉結合を作らない。
2. 結合に使用するカラムは提示された表構造に存在する英語物理名のみを使う。
3. 削除フラグがある表では、有効データのみを対象にする条件を付与する。
4. SELECT 句には `*` を使わず、必要なカラムを明示する。
5. SQL 変数は指定された書式をそのまま使う。値を推測して埋め込まない。
6. ORDER BY が必要な場合は主キーまたは日付カラムを使用する。
7. 説明文・コードフェンス・セミコロン後のコメントは出力せず、SQL 文のみを出力する。
