## 修正ルール

1. メソッド・クラス・フィールドの Javadoc を日本語に統一する。
2. 各 Javadoc に「何をするか」と「なぜそうするか」を簡潔に含める。
3. @param / @return / @throws の説明を実際のシグネチャと一致させる。
4. コードの振る舞い・制御構造・型は一切変更しない。
5. 説明文やコードフェンスは出力せず、修正後の Java ソースのみを出力する。
