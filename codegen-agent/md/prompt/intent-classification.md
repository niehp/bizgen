## 判定基準

- NEW_FILE: 新しい Java ファイルを 1 つ作成する場合。
- ADD_METHOD: 既存クラスにメソッドを追加する場合。
- MODIFY_METHOD: 既存クラスの既存メソッドを修正する場合。

機能定義に明示的な指定がある場合は、それを最優先してください。

## 出力形式

JSON オブジェクトのみを出力してください。前後の説明文・コードフェンスは禁止です。

{"intent":"NEW_FILE または ADD_METHOD または MODIFY_METHOD","reason":"判定根拠を日本語で1文"}
