## 生成ルール

1. SET 句・WHERE 句のカラムは提示された表構造に存在する英語物理名のみを使う。
2. 更新対象を特定する WHERE 句を必ず付ける。全件更新になる SQL は生成しない。
3. 楽観ロック用の更新日時カラムがある場合は、WHERE 句に現在値の比較を追加する。
4. 削除ではなく更新であること。DELETE 文を出力しない。
5. SQL 変数は指定された書式をそのまま使う。値を推測して埋め込まない。
6. 説明文・コードフェンスは出力せず、SQL 文のみを出力する。
