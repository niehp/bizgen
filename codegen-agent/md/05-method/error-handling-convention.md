# メソッド実装規約（メソッド級）

## 引数と戻り値

- 引数は 4 つ以下にする。増える場合はコマンドオブジェクトを検討し、md に根拠を残す。
- 検索系は「0 件」を例外にしない。空の `Optional` / 空リストを返し、呼び出し側の分岐を単純にする。
- 更新系は存在確認と楽観ロックを生成側で行い、競合は例外にする。

## 判定の置き場所

- 必須チェック・形式チェックなど決定論的な判定はモデルに書かせず、Java 側のコードで行う。
- モデルが担当するのは、機能 md の日本語を既存 API の組み合わせへ対応付けることだけ。

## 日本語 Javadoc

メソッド Javadoc には「何をするか」を 1 文、「なぜそうするか」を 1 文書く。

例:

```java
/**
 * 受注IDで受注を1件検索する。
 * 未検索時も例外とせず空の結果を返し、呼び出し側の分岐を減らす。
 */
```
