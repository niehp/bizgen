# DB アクセス規約（プロジェクト共通）

## 基本方針

- SQL は Java 文字列に直接埋め込まず、リソースまたは定数として分離する。
- 更新系 SQL には楽観ロック using version 列を付与する。
- 削除は原則として論理削除とし、`delete_flag` を更新する。
- 複数表を結合する検索では、結合条件をすべて明示し、暗黙の交叉結合を避ける。

## 表構造 md

- `md/schema/` に 1 表 1 ファイルで配置する。
- 日本語名・英語物理名・カラム日本語名・カラム英語物理名・型を必ず記載する。
- LLM へ渡す表構造は SQL で使用する表に限定する（上限は `gen.maxTables`）。

## SQL 変数

| 型 | 記述例 |
| --- | --- |
| 文字列型 | `/*customerName*/'xx';` |
| 日付型 | `/*orderDate*/CURREN_DATE;` |
| 数値型 | `/*orderId`*/9;` |

変数名は小駝峰で統一する。`/*` と `*/` は SQL コメントとして扱われ、実行時にバインド値へ置換される。
