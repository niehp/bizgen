# 顧客（m_customer）

## 基本情報

- 日本語名: 顧客
- 英語物理名: m_customer
- 概要: 顧客マスタ。受注表から参照される。

## カラム定義

| 日本語名 | 英語物理名 | 型 | 主キー | NOT NULL | 備考 |
| --- | --- | --- | --- | --- | --- |
| 顧客ID | customer_id | STRING | ○ | ○ | 顧客を一意に識別する |
| 顧客名 | customer_name | STRING |  | ○ | 漢字氏名 |
| 顧客カナ | customer_kana | STRING |  |  | フリガナ |
| 登録日 | registration_date | DATE |  | ○ | 顧客登録日 |
| 削除フラグ | delete_flag | STRING |  |  | 0:有効 1:削除済み |

## 型の取り扱い

- `STRING` : SQL 変数は `/*customerName*/'xx';`
- `DATE`   : SQL 変数は `/*customerDate*/CURREN_DATE;`
- `NUMBER` : SQL 変数は `/*customerNo`*/9;`

## リレーション

| from | to | 結合条件 |
| --- | --- | --- |
| 顧客 | 受注 | 顧客.顧客ID = 受注.顧客ID |
