# 受注（t_order）

## 基本情報

- 日本語名: 受注
- 英語物理名: t_order
- 概要: 受注ヘッダ情報を管理する表。

## カラム定義

| 日本語名 | 英語物理名 | 型 | 主キー | NOT NULL | 備考 |
| --- | --- | --- | --- | --- | --- |
| 受注ID | order_id | STRING | ○ | ○ | 受注を一意に識別する |
| 顧客ID | customer_id | STRING |  | ○ | 顧客表への外部キー |
| 受注日 | order_date | DATE |  | ○ | 受注が発生した日付 |
| 受注金額 | order_amount | NUMBER |  |  | 税込金額 |
| 削除フラグ | delete_flag | STRING |  |  | 0:有効 1:削除済み |
| 更新日時 | update_timestamp | DATE |  |  | 楽観ロック用 |

## 型の取り扱い

- `STRING` : SQL 変数は `/*customerName*/'xx';`
- `DATE`   : SQL 変数は `/*orderDate*/CURREN_DATE;`
- `NUMBER` : SQL 変数は `/*orderId*/9;`

## リレーション

| from | to | 結合条件 |
| --- | --- | --- |
| 受注 | 顧客 | 受注.顧客ID = 顧客.顧客ID |
