# maskPhone

- **方法签名**: `public static String maskPhone(String phone)`
- **所属类**: `com.company.common.util.MaskUtils`
- **功能描述**: 将中国大陆 11 位手机号的中间 4 位替换为 `*`（如 `13812345678` -> `138****5678`）。如果传入为 `null`、空字符串或长度不是 11 位的纯数字，则原样返回（不抛异常）。

## 使用例

### 例 1：正常 11 位手机号脱敏
```java
import com.company.common.util.MaskUtils;

String masked = MaskUtils.maskPhone("13812345678");
// 结果: "138****5678"
